# AI Model Research & Benchmarks

This directory contains research on Google Gemini models, prompt token analysis, and evaluation benchmarks.

- **Primary Models:** `gemini-3.7-flash` (Writing, Speaking, AI Coach), `gemini-3.5-flash-lite` (Utilities).
- **Fallback Models:** `gemini-2.5-pro` (Deep reasoning fallback), `gemini-2.5-flash` (Previous generation Flash fallback).
- **Core Document:** See `project/docs/ai-model-decision.md` for the active production strategy.
