# Research & Analysis Directory

This directory stores all background research, technical evaluations, format specifications, and UX analysis to keep the application source directory clean and lightweight.

---

## Structure

- **`ai-models/`**: Comprehensive benchmarks, model lifecycle reports, and token economics for Google Gemini models.
- **`aptis-format/`**: Public specifications of Aptis General B2 exam tasks (Reading 1-4, Listening 1-4, Writing 1-4, Speaking 1-4, Grammar & Vocabulary), timing constraints, and CEFR B2 descriptors.
- **`ux-reference/`**: SaaS layout benchmarks, card-based navigation, exam simulator interaction patterns.
- **`technical-decisions/`**: Architecture Decision Records (ADRs).
