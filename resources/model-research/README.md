# Gemini Model Research Notes (August 2026)

This directory stores deep-dive benchmark summaries and Google DeepMind release analyses.

---

## Key Model Milestones Tracked

1. **`gemini-3.7-flash` (GA 2026-08-13):**
   - High-throughput multimodal workhorse.
   - Pricing: $0.75 / 1M input, $3.75 / 1M output.
   - Ideal for agentic tasks, CEFR evaluation, and multimodal speech feedback.

2. **`gemini-3.5-flash-lite` (GA 2026-07-21):**
   - High-speed low-cost utility engine (350 tokens/sec).
   - Pricing: $0.30 / 1M input, $2.50 / 1M output.
   - Ideal for vocabulary lookups, grammar explanations, and fast classification.

3. **`gemini-2.5-pro` & `gemini-2.5-flash` (GA Mid-2025):**
   - Stable generation models serving as reliable fallback options.

4. **Legacy Deprecations (June 1, 2026):**
   - `gemini-2.0-flash`, `gemini-2.0-flash-lite`, `gemini-1.5-pro`, `gemini-1.5-flash` reached end-of-life and are not used.
