# Câu Bị Động (Passive Voice)

## 1. Công Thức Tổng Quát
$$ \text{Active: } S + V + O \longrightarrow \text{Passive: } S_{new} + \mathbf{be + V_{3/ed}} + (by + O_{new}) $$

## 2. Các Dạng Bị Động Trọng Tâm Trong Aptis B2
1. **Quá khứ đơn:** `was / were + V3/ed` (*The event was broadcasted last month.*)
2. **Hiện tại hoàn thành:** `have / has + been + V3/ed` (*The bridge has been repaired.*)
3. **Modal verbs bị động:** `modal + be + V3/ed` (*The rules must be followed.*)
4. **Bị động tiếp diễn:** `is / are / was / were + being + V3/ed` (*The car is being fixed now.*)
