# Tổng Hợp Phân Tích Dữ Liệu 16 Bộ Đề Thi Thử (WebAptis Mock Tests)

Hệ thống WebAptis B2 sở hữu 16 bộ đề thi thử hoàn chỉnh 5 kỹ năng được chuẩn hóa từ kho đề thi thực tế:

| Kỹ năng | Quy mô dữ liệu trên 16 đề | Đặc điểm cấu trúc |
| :--- | :--- | :--- |
| **Grammar & Vocabulary** | 800 câu hỏi trắc nghiệm (50 câu/đề) | 25 câu ngữ pháp (3 lựa chọn) + 25 câu từ vựng (4 dạng) |
| **Reading** | 64 Parts (4 Parts/đề, 464 câu hỏi) | 16 P1 Sentence Completion, 16 P2 Ordering, 16 P3 Matching, 16 P4 Long Text |
| **Listening** | 64 Parts (384 câu hỏi) + 15 MP3 Audio gốc | 13 câu P1/đề, 4 câu P2/đề, 4 câu P3/đề, 2 câu P4/đề |
| **Writing** | 64 Parts (24 đề câu lạc bộ dự đoán) | P1 short form, P2 club interest, P3 chatroom, P4 formal/informal email |
| **Speaking** | 64 Parts (110 bài tập practice, 94 chủ đề dự đoán) | P1 personal info, P2 describe photo, P3 compare photos, P4 2-min presentation |
